# Каталог учреждений

Чистый Dart-пакет с проверенным локальным снимком публичных фактов для
Санкт-Петербурга и Воронежа. Состав, источники, дата и ограничения описаны в
[реестре](../../docs/provider-directory-sources.md) и
[ADR 0016](../../docs/adr/0016-local-provider-directory.md).

`bundledDirectory()` загружает неизменяемый каталог. `ProviderCatalog.search`
фильтрует по `testIds` из закреплённого словаря типов исследований и сортирует отдельные места приёма по расстоянию
от `GeoPoint`. Расстояние — по прямой; предложения анализов уровня сети
помечаются `needsConfirmation` и не становятся подтверждёнными услугами филиала.

`testOptions(city)` возвращает единые RU/EN-пункты выбора; `mappingFor(test)`
сохраняет доступ к проверенному соответствию источника. Неизвестные формулировки
получают отдельные `source:<id>` и не объединяются автоматически.
Исходные названия в `ProviderTest.name` сохраняются.

Обновление из корня репозитория:

```sh
python3 tool/build_provider_catalog.py
dart format packages/provider_directory/lib
```

Из каталога пакета: `dart analyze`, `dart test`. Агенты запускают тесты через
MCP `run_tests`. Исходные факты редактируются в `data/catalog.json` с новой версией
и датой проверки. Генератор не получает данные из сети.
