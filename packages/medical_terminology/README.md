# medical_terminology

Чистый Dart-пакет: неизменяемые выпуски показателей и единиц, локальный точный
поиск с контекстом и явное подтверждение привязки к ручному результату.
Публичный вход — `lib/medical_terminology.dart`.

`bundledTerminology` содержит внутренний пилот из четырёх показателей и четырёх
единиц. Поиск возвращает `unknown`, `unique` или `ambiguous`, не меняет медицинские
записи и не угадывает единицы. `confirm` вызывается после выбора пользователя.
Исходные строки сохраняются в `LabResultCoding`, значения не пересчитываются.

При изменении данных добавляйте новый выпуск с новым ID и сохраняйте прежний
в каталоге. Один ID не должен обозначать разное содержимое. В пакете нет I/O,
сетевых запросов, Flutter, медицинской интерпретации и импортированных кодов.
