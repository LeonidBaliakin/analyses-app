# medical_domain

Чистое Dart-ядро без Flutter, I/O, FFI и браузерных импортов. `CalendarDate` представляет полную григорианскую дату без времени и часового пояса; тип не обозначает точный момент, приблизительный период или неполную дату.

Реализованы профиль, лабораторный результат, курс препарата, домашнее измерение,
исходное значение без потери десятичных разрядов, проверка периода и времени,
порт `HealthRecordsRepository` и сценарий сохранения `HealthRecords`.
Хранение и JSON DTO принадлежат `local_store`; публичный вход ядра —
`lib/medical_domain.dart`. [Контракт и ограничения](../../docs/local-records.md).
