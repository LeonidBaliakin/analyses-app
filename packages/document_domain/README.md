# document_domain

Чистое Dart-ядро без Flutter, I/O и браузерных API: неизменяемые метаданные
оригинала, SHA-256, проверка сигнатуры PDF/PNG/JPEG и порты repository/Documents.
Размер оригинала ограничен 20 МиБ. Исходное имя является подписью, не путём.

[Контракт и пределы](../../docs/adr/0008-originals-and-documents.md).
