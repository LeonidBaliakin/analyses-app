# Независимые коннекторы медицинских сетей

Семь `bin/{network}.dart`, семь отдельных AOT-образов и Compose services.
`CONNECTOR_SOURCE` — аргумент **сборки**, а не переключатель сети во время работы.
Каждый процесс принимает `DIRECTORY_ENDPOINT`, собственный `DIRECTORY_CONNECTOR_KEY`
и optional `CONNECTOR_BIND`. У него нет доступа к PostgreSQL и ключам соседей.

`--once` выполняет один опрос/сбор и завершает процесс; штатный режим опрашивает
реестр каждые 15 секунд. `/health` на 8090 проверяет живость процесса и недавнюю
связь с реестром. `--health` — probe из контейнера. Метрики журналов содержат
идентификатор источника, задания и код ошибки, без исходных страниц и значений.
