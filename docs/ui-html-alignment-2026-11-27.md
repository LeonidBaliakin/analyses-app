# Сверка Flutter с новым index.html — APK 0.1.7

Эталон — актуальный корневой `index.html`, полученный из `origin/main`.
Сверка выполнена по отрисованному HTML, включая изменения, добавляемые JavaScript.
Flutter сохраняет MVVM, чистое Dart-ядро и платформенные адаптеры.

## Архитектура и данные

Views отображают состояние, ViewModels содержат команды и черновики. Композиция
в `records` передаёт ожидаемую ревизию и стабильные ID операций в репозиторий.
Новые медицинские типы и проверка сохранения находятся в чистом Dart. Компоненты
оформления не импортируют медицинские сервисы.

[ADR 0018](adr/0018-profile-context-and-reviewed-events.md) фиксирует контекст
профиля, payload формата 4, подтверждение рассказа и локальную атомарность набора.
Старые свободные поля, исходные строки, история и прежние outbox-команды
сохраняются. Синтетический профиль не импортируется после входа.

В PDF включаются выбранные строки и даты; события — при включённой шкале.
Кириллица, знак сравнения и исходная точность проверены на отдельном
синтетическом PDF. Статические Regular/Bold подготовлены из поставляемого
Manrope; шрифты и данные при генерации не скачиваются.

## Существенные границы

Физические телефоны, планшеты и foldable в этой задаче не подключались. Поворот
ОС не блокируется. Нативные поля даты, системные диалоги и раскладка при крупном
шрифте используют возможности Flutter и платформы.

Реальные записи не получают демонстрационную оценку «в норме» или выдуманный срок
действия. Для времени измерения нужен явный UTC offset; дата без времени остаётся
датой. Год в рассказе без года требует уточнения вместо автоматической догадки.
Собственного native ASR нет: доступна подсказка диктовки клавиатурой.

QR, почтовая пересылка и отправка в поддержку сохраняют границы существующих
адаптеров. Изменение интерфейса не выдаёт серверные права и не подключает доставку.
Новые поля профиля требуют Records-сервера с форматом 4 для синхронизации;
до обновления сервера сохраняются локальные редакции и outbox. Серверы здесь
не развёртывались; PostgreSQL API-тесты не запускались — локальный порт стенда
55438 был недоступен.
