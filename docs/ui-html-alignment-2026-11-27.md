## Карта переноса

| Область | Поведение после изменения |
|---|---|
| История / отчёт | Единый полноэкранный `/history` для демопримера и подтверждённых локальных записей. Прямая ссылка возвращается на сводку. |
| Таблица | Группы систем, закреплённые названия и шапка дат, синхронная вертикальная прокрутка, горизонтальная прокрутка дат и кнопки перемещения. Из названия открываются подробности. |
| Фильтры | Вся история, последняя сдача, две последние, свой включительный диапазон. Несколько показателей выбираются через поиск; плашки остаются после сворачивания поиска. Ошибочные даты блокируют экспорт. |
| Поворот | Поворачивается представление, без блокировки ориентации ОС. Физическое изменение ориентации сбрасывает ручной поворот, сохраняя фильтры. |
| События | Сворачиваемые дорожки по месяцам, полосы препаратов и метки событий; подписи дорожек закреплены, подпись длинной полосы остаётся видимой. Есть подробности события. |
| Печать | HTML использует те же даты и выбранные строки. Сохраняются исходные значения, единицы, референсы, источник, заметки и известный фрагмент документа. События включаются при открытом графике. На мобильных платформах сохранено копирование текста. |
| Сводка | Единый вход в историю; убрана избыточная панель выбора систем, сохранены поиск, цветные системы и четыре фильтра последней сдачи. Сравнение и список событий открываются на весь экран. |
| Анализы / загрузка | Упрощённая история сдач и единое окно загрузки. Адрес пересылки вынесен в раскрываемый блок и копируется с сообщением об успехе/ошибке. Локальные результаты сгруппированы по дате и лаборатории без объединения записей. |
| Дневник | Быстрые действия открывают существующие локальные формы измерения/курса. Сохранение возвращает в дневник; повторное открытие не создаёт вторую запись. Демособытия сгруппированы по месяцам. |
| Профиль / настройки | Короткое введение, раскрываемое объяснение связи с анализами, основные данные первыми. Разделы доступов раскрываются отдельно, добавлен выбор темы обращения. Настоящие настройки не помечаются общим демобаннером. |
| QR | Отдельный раздел доступа: длительность, период, состав систем и события. Пример ссылки копируется; управление доступами ведёт в настройки. Демо обозначено явно. |
| Первые шаги | Последний шаг посвящён QR. Действия открывают профиль/загрузку/историю и возвращают к текущему шагу. Завершение открывает добавление анализа, пропуск возвращает на исходный экран. |
| Каталог | Фильтр сети с адаптивной раскладкой; дата публикации отделена от дат проверки адреса и врача. Общий телефон сети подписан, при отсутствии номера нет пустой кнопки звонка. |

Новые строки добавлены в RU/EN; используется текущая светлая/тёмная палитра и
сохраняемые настройки приложения.

## Границы

Формат медицинских записей, SQLite и протокол синхронизации не изменены.
Совместимость серий вычисляет `HealthReport`: похожее название не объединяет
неизвестные результаты. График реальных данных получает курсы и измерения;
болезни, жалобы и госпитализации деморежима остаются синтетическими — новый тип
подтверждённой записи для них не добавлен.

Встроенного native PDF-export нет: web/desktop сохраняет HTML для печати через
браузер; Android/iOS предлагает копирование текста. QR не выдаёт реальные права.
Пересылка почты, настоящие доступы, доставка уведомлений и отправка обращения
в поддержку не подключаются этой правкой. Исходные цены новых парсеров не
публикуются в проверенном клиентском каталоге автоматически.

Android/iOS runtime и физический foldable не проверялись; адаптивность проверена
widget-тестами. Серверы не развёртывались.
