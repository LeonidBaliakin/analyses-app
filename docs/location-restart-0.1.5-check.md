# Проверка подтверждения местоположения в 0.1.5

Дата: 27 ноября 2026. Проверка выполнена на отдельном Android-эмуляторе
API 37 / arm64, без данных пользователя. Интерфейс эмулятора — английский.

## Проверенный APK

Проверялся уже собранный `orange-of-health-0.1.5-arm64.apk`, без пересборки.
Android подтвердил `versionName=0.1.5`, `versionCode=6`; приложение не debug.
SHA-256 файла:

```text
8aaa680270ddd938f9670a1bddcff4276a0bbb7577d3da56f15d0e9873c1e769
```

Перед проверкой сохранён тестовый адрес `Voronezh, Voronezh Oblast, Russia`.
Он выбран через настоящий поиск адресов. Разрешения приблизительной и точной
геопозиции выданы. Данные приложения при перезапусках не очищались.

## Полный перезапуск с выключенной геолокацией

1. Геолокация выключена через Android; `cmd location is-location-enabled`
   вернул `false`.
2. Адрес подтверждён. Приложение полностью остановлено через
   `am force-stop app.analyses.health_app`; `pidof` подтвердил отсутствие
   процесса. Новый запуск был `COLD`, PID изменился с 6625 на 7014.
3. При открытии лабораторий появилось окно **Are you here?** с сохранённым
   адресом, кнопками **Yes, I am here** / **No, enter another address** и
   сообщением о недоступной геолокации. До подтверждения отображалось
   **Location not selected**.
4. После подтверждения окно закрылось, адрес появился в каталоге.
5. Переход к врачам в той же сессии сохранил адрес и не вызвал повторный вопрос.

Результат: пройдено. Подтверждение прошлого запуска не переносится в новый,
сохранённый адрес доступен при выключенном GPS.

## Полный перезапуск с включённой геолокацией

1. `cmd location is-location-enabled` вернул `true`.
2. После подтверждения в предыдущей сессии выполнена полная остановка;
   `pidof` не нашёл процесс. Новый запуск был `COLD`, PID 7014 → 7911.
3. При открытии лабораторий Google Play Services предложил включить
   Location Accuracy. Выбрано **No thanks**.
4. Приложение показало **Are you here?**, тот же сохранённый адрес и действия
   подтверждения/изменения. Адрес не был назначен автоматически.

Результат: пройдено для отказа от системного предложения геолокации.
Свежая GPS-позиция в этом прогоне не получена.

## Дополнительная проверка состояния

До проверки APK использовалась отдельная debug-точка входа
[`location_restart_app.dart`](../apps/health_app/integration_test/location_restart_app.dart).
Она вызывает обычный `main()` приложения, не подменяет хранилище или GPS и
добавляет только Flutter Driver с чтением состояния. В production entrypoint
расширение отсутствует. Эта проверка относится к рабочему дереву, отдельно от
проверки неизменного APK выше.

После реальной остановки Android-процесса и нового запуска:

- `confirmed=false`, `currentAddress=null`, последний адрес восстановлен;
- с выключенной геолокацией: `issue=serviceDisabled`, сохранённый адрес
  предложен для подтверждения, `busy=false`;
- с включённой геолокацией без выданной эмулятором позиции: после тайм-аута
  `issue=timeout`, сохранённый адрес предложен для подтверждения;
- нажатие подтверждения: `confirmed=true`, текущий адрес назначен;
- переход между лабораториями и врачами не открывает вопрос повторно.

Для интерактивного повторения из `apps/health_app`:

```bash
flutter run --debug -d <test-device-id> --target integration_test/location_restart_app.dart --print-dtd
```

Полный перезапуск проверяется остановкой процесса Android и новым запуском,
а не hot restart. После остановки требуется заново подключить Flutter Driver
к VM Service нового процесса.

Дополнительно прошли 38 unit/widget-тестов из `location_session_test.dart`,
`device_access_widget_test.dart` и `app_introduction_test.dart`. Анализ и
проверка форматирования debug-точки входа прошли; hot reload этой точки входа
выполнен до установки исходного APK. Относительные ссылки отчёта и
`git diff --check` проверены. SHA-256 исходного APK после проверки не изменился.

## Границы проверки

Проверка выполнена на эмуляторе, не на Galaxy Z Fold 8. Получение нового адреса
от физического GPS этим результатом не подтверждается. Геолокационный сценарий
без сохранённого адреса здесь отдельно не проверялся.
