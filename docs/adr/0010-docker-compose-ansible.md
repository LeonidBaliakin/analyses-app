# ADR 0010: Docker Compose и Ansible для серверных сервисов

Дата: 24 ноября 2026 года. Статус: принято по требованию владельца проекта.

## Решение

Все серверные сервисы, включая OCR/LLM runtimes и инфраструктурные зависимости,
запускаются в Docker через Compose. Для быстрого развёртывания и повторного обновления
поддерживается Ansible. Новый серверный сервис добавляется вместе с Dockerfile или
закреплённым образом, Compose-конфигурацией, Ansible-задачами, persistent storage,
миграциями и проверкой готовности. Хостовые процессы приложения не являются частью
серверного deployment.

[Серверный Compose](../../infra/server/compose.yaml) содержит PostgreSQL, SeaweedFS,
Documents, Processing и отдельный inference. [Плейбук](../../infra/ansible/deploy.yml)
устанавливает Docker на Ubuntu 24.04, копирует только build inputs, проверяет SHA
модели/OCR, создаёт стабильные секреты и запускает стек с проверкой API. Идемпотентный
Compose-job создаёт отдельную БД Processing и не удаляет существующие данные.
Секреты остаются на сервере; исходники, модели и секреты не запекаются в один образ.

По умолчанию API доступен через loopback/SSH-туннель либо существующий HTTPS proxy.
Внутренние БД, S3 и LLM не публикуют host-порты. Первый срез остаётся пилотом с bootstrap
авторизацией ADR 0008/0009; этот ADR определяет способ запуска и не объявляет готовность
публичного медицинского сервиса. CPU inference — начальный переносимый deployment;
отдельный GPU-вариант и автоматические бэкапы ещё не подготовлены.

## Альтернативы и последствия

- Хостовый llama-server допустим для локальной разработки на Mac с Metal, но не для
  сервера. `infra/documents` остаётся development-стендом; сервер использует `infra/server`.
- Systemd для отдельных процессов приложения отвергнут: увеличивает различия стендов.
  Systemd используется только для Docker daemon на Ubuntu.
- Kubernetes отложен: текущий срез имеет один Processing worker и один сервер;
  распределённое масштабирование пока не обосновано.

Фиксированный digest inference входит в runtime ID, поэтому серверный контейнер и
Mac runtime могут иметь разные версии. Повтор обработки при смене runtime создаёт
новое задание и сохраняет прежние черновики. [Инструкция](../../infra/ansible/README.md).
