# Доступ к возможностям устройства

## Решение

Камера, медиатека, файлы и геолокация подключаются через внедряемый `DeviceAccessGateway` в Flutter-приложении. Адаптер использует `image_picker`, `file_selector` и `geolocator`; медицинское Dart-ядро от них не зависит. `DeviceAccessViewModel` владеет командами, выбором текущего сеанса и состояниями отказа, ограничения, отмены, тайм-аута и недоступности. Одновременно выполняется одна команда, чтобы повторные нажатия не открывали несколько системных окон.

При первом входе автоматически показывается окно доступа. Оно предлагает выбрать файл и определить местоположение и позволяет продолжить без разрешений. Системный запрос открывается кнопкой пользователя, что сохраняет совместимость с браузерами. Завершение окна сохраняется локально отдельно от разрешений ОС. При действии разрешения заново проверяет адаптер: флаг знакомства не считается действующим разрешением. Последующее знакомство с разделами приложения запускается через `onReady` после закрытия окна доступа.

Съёмка открывает системную камеру; фото — системную медиатеку; документ — системное окно файлов. Доступ выдаётся на выбранный объект. Широкие `MANAGE_EXTERNAL_STORAGE`, `READ/WRITE_EXTERNAL_STORAGE`, доступ ко всей медиатеке и фоновая геолокация не требуются. `requestFullMetadata: false` не запрашивает дополнительное разрешение метаданных фото на iOS. Android-камера вызывается внешним intent без собственного разрешения `CAMERA`; назначение камеры и медиатеки на iOS объявлено в `Info.plist`.

Геопозиция определяется однократно с ограничением времени 20 секунд; допустима приблизительная точность. В обоих каталогах доступны повторный запрос, настройки там, где их поддерживает адаптер, и ручной город/адрес. Неудачный запрос не стирает прежний адрес. В обоих каталогах отображается читаемый адрес. Подсказки ввода, преобразование GPS в адрес через внешний Photon, локальное сохранение последнего адреса и подтверждение на каждый запуск приложения определены в [ADR 0015](0015-location-address-confirmation.md). Эта часть уточнена 2026-11-26; строки запроса или GPS-координаты передаются сервису поиска адресов с пояснением в UI.

Выбранные файлы остаются в памяти при закрытии окна и изменении размера. Это ещё не импорт или сохранение оригинала: SHA-256, медицинское хранилище, OCR и AI не вызываются. UI сообщает, что после перезапуска файл нужно выбрать повторно. Результат `image_picker` после уничтожения Android Activity восстанавливается однократно при запуске.

## Платформы и пределы

| Платформа | Файлы / фото | Съёмка | Геопозиция |
|---|---|---|---|
| Android | Document/photo pickers | Внешняя камера | Foreground coarse/fine; настройки ОС |
| iOS | Document picker / PHPicker | Камера и запрос по действию | When-in-use; настройки приложения |
| macOS | Диалог файлов, sandbox `user-selected.read-only` | В текущем адаптере недоступна; доступны фото/файлы | CoreLocation, purpose string и location entitlement |
| Windows | Диалог файлов | В текущем адаптере недоступна | Системный провайдер при наличии |
| Linux | Диалог файлов | В текущем адаптере недоступна | GeoClue при наличии сервиса и разрешений |
| Web | Выбор браузера | Зависит от поддержки `capture`; возможен обычный выбор изображения | HTTPS/localhost и разрешение сайта |

Доступность камеры проверяет `supportsImageSource`; отсутствие плагина или устройства возвращает явный результат с альтернативой. Сборка не подтверждает наличие оборудования или выдачу разрешений. Каталог остаётся синтетическим: адрес не геокодируется, координаты не меняют демонстрационные расстояния; это указано на экране.

При iOS-сборке с Swift Package Manager используется `BYPASS_PERMISSION_LOCATION_ALWAYS=1 flutter build ios …`, чтобы исключить неиспользуемую ветку фонового доступа плагина. В `Info.plist` объявлен только when-in-use. При переходе на CocoaPods соответствующий define задаётся target `geolocator_apple` в `post_install`.

## Альтернативы

- Общий `permission_handler` и широкие storage/photo-разрешения: не дают универсального файлового доступа и не нужны системным pickers.
- Все разрешения при каждом старте: повторяет отклонённые запросы; первое окно и запрос по действию оставляют возможность продолжить без разрешений.
- Плагины непосредственно во Views: затрудняют проверку отказов, защиту от повторов и общий выбор местоположения между каталогами.

Контракты сверены с документацией [image_picker](https://pub.dev/packages/image_picker), [file_selector](https://pub.dev/packages/file_selector), [geolocator](https://pub.dev/packages/geolocator) и исходниками установленных версий.
