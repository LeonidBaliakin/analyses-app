# Динамика анализов

Прототип приложения: человек загружает анализы из разных лабораторий, видит динамику по каждому показателю и показывает её врачу.

Каталог Санкт-Петербурга и Воронежа содержит реальные учреждения, врачей,
анализы и контакты. Подтверждённый адрес или геолокация задают точку сортировки
по расстоянию. Локальный снимок включает семь сетей, в том числе МедЭксперт и ЦСП.
Реализованы серверный реестр, регулярные задания и отдельный микросервис на сеть;
Flutter может обновлять каталог с офлайн-кешем. [Источники](docs/provider-directory-sources.md),
[запуск и границы автоматической публикации](docs/operations/provider-connectors.md).

## Как посмотреть

Откройте `index.html` в браузере. Всё работает в одном файле, без сервера. Данные демонстрационные; изменения сохраняются только в браузере.

## Flutter-каркас

Приложение в `apps/health_app` повторяет дизайн HTML-прототипа Orange of Health: Manrope, лавандовый фон, оранжевое меню, цветные системы, сводка, бланки, профиль, каталоги и доступ врачу. Демонстрационные данные взяты из исходного прототипа и не являются сохранёнными медицинскими записями. Доступны RU/EN, светлая/тёмная/системная тема и адаптивная навигация. Выбор языка и темы сохраняется на устройстве. Добавлены локальные профиль, ручные результаты, курсы препаратов и домашние измерения с сохранением в SQLite, историей правок и обработкой ошибок. Деморежим открывается отдельно. Добавлены оригиналы, OCR/LLM-черновики с ручным подтверждением, отчёты и синхронизация;
[аккаунты и сессии](docs/accounts-and-sessions.md) подключают обычный вход по email.
Ограничения каждого среза описаны в соответствующих контрактах. [Контракт и ограничения локальных записей](docs/local-records.md). HTML-демо остаётся отдельным прототипом.

```bash
flutter pub get
cd apps/health_app
flutter run -d chrome
```

SDK: Flutter 3.50.0 / Dart 3.14.0. [Структура, команды и границы реализации](docs/project-structure.md), [решения каркаса](docs/adr/0004-flutter-scaffold.md).

## Разработка приложения

Текущий рабочий вариант — Flutter/Dart для iOS, Android, web и desktop, общее локальное ядро и независимые UI-модули по MVVM. Облачная часть включает хранение оригиналов в SeaweedFS OSS, медицинские словари, серверные OCR/LLM или AI API, отдельные каналы уведомлений и коннекторы источников. Каркас, локальные записи, минимальный словарь и путь оригиналов SQLite → Documents → SeaweedFS с проверкой SHA-256 реализованы ([ADR 0008](docs/adr/0008-originals-and-documents.md)); полный состав медицинского ядра и облачных сервисов пока описан на уровне архитектуры.

Будущее приложение поддерживает русский и английский интерфейс, светлую, тёмную и системную тему. Мобильные раскладки рассчитаны на телефоны, планшеты и складные телефоны, включая изменение размера окна и состояния сгиба.
