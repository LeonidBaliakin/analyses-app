# Динамика анализов

Прототип приложения: человек загружает анализы из разных лабораторий, видит динамику по каждому показателю и показывает её врачу.

## Как посмотреть

Откройте `index.html` в браузере. Всё работает в одном файле, без сервера. Данные демонстрационные; изменения сохраняются только в браузере.
